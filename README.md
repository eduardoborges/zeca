# Zeca

<img src="site/assets/zeca.svg" width="96" alt="Zeca logo">

Zeca is a macOS meeting recorder that transcribes and summarizes everything on your Mac. Named after a real dog.

**Site:** https://zeca.eduardoborges.dev

## What it does

- **Records both sides of a call** — microphone and system audio as separate tracks (ScreenCaptureKit), works with any meeting app.
- **Live transcription** — Parakeet TDT v3 running on the Neural Engine, sentence-by-sentence with silence-based segmentation. Multilingual with automatic language detection.
- **Two clean tracks** — your microphone is "You", everything else is "Others"; simple labels the summarizer never trips on. Both renameable with a double click.
- **Summaries and notes** — Quick recap + per-person next steps, plus a detailed point-by-point account in reported speech. Generated by Claude (your API key) or fully on-device with Apple Intelligence.
- **Translation** — transcript, summary and notes translatable on demand, cached per language.
- **Your day** — dashboard with today's events (macOS Calendar and/or Google Calendar via OAuth), one click to join a call already recording, weekly stats.
- **Quality of life** — automatic titles for unnamed meetings, pause that truly excludes audio, menu bar timer with controls, live summary refreshed every minute.

Everything is stored as plain files under `~/Library/Application Support/ZecaAI/Recordings/<timestamp>/`:

```
mic.m4a  system.m4a         audio tracks
meeting.m4a                 combined mix (created on first play)
transcript.json             turns with speaker, start/end, text
summary.md  notes.md        generated documents
title.txt  offsets.json     metadata
translation-<lang>.json     cached translations
```

## Requirements

- macOS 15+ (Liquid Glass UI on macOS 26; on-device summaries need macOS 26 with Apple Intelligence)
- Xcode 16+
- Optional: Anthropic API key (summaries via Claude), Google OAuth client (calendar integration)

## Build

```bash
xcodebuild -project ZecaAI.xcodeproj -scheme ZecaAI -configuration Debug build
```

Or open `ZecaAI.xcodeproj` in Xcode and run. First launch downloads the Parakeet model (~650 MB) and asks for screen-recording, microphone and calendar permissions.
